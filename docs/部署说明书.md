## 2. Docker 部署（推荐）

项目根目录提供 docker-compose.yml，一键启动全部中间件。

### 2.1 启动

`ash
cd D:\a22
docker-compose up -d
`

### 2.2 服务端口

| 服务 | 容器端口 | 宿主机端口 |
|------|---------|-----------|
| MySQL | 3306 | 3307 |
| Redis | 6379 | 6379 |
| Kafka | 9092 | 9092 |
| Flink JobManager | 8081 | 8081 |

### 2.3 验证

`ash
docker-compose ps
`

浏览器打开 Flink Dashboard：http://localhost:8081

### 2.4 停止

`ash
docker-compose down
`

> ⚠️ Docker 方式部署时，后端 pplication.yml 中的数据库端口需改为 3307，或将 MySQL 宿主机端口改为 3306。

## 3. 手动部署（Windows 本地）

### 3.1 MySQL

**安装路径**：C:\Program Files\MySQL\MySQL Server 8.4\

**启动**：
`ash
# 以管理员身份运行
net start mysql84
`

**创建数据库**：
`sql
CREATE DATABASE IF NOT EXISTS a22 DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;
`

**验证**：
`ash
mysql -u root -p -e "SHOW DATABASES;"
`

> 表结构由 JPA ddl-auto: update 自动创建，无需手动建表。

### 3.2 Redis

**启动**（默认端口 6379）：
`ash
redis-server
`

**验证**：
`ash
redis-cli ping
# 返回 PONG 表示正常
`

### 3.3 Kafka

**安装路径**：D:\kafka\

**启动顺序**：先 Zookeeper，再 Kafka。

**① 启动 Zookeeper**：
`ash
D:\kafka\bin\windows\zookeeper-server-start.bat D:\kafka\config\zookeeper.properties
`

**② 启动 Kafka Broker**（新终端）：
`ash
D:\kafka\bin\windows\kafka-server-start.bat D:\kafka\config\server.properties
`

**③ 创建 Topic**（新终端）：
`ash
D:\kafka\bin\windows\kafka-topics.bat --create --topic a22-transactions --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
`

**④ 验证**：
`ash
D:\kafka\bin\windows\kafka-topics.bat --list --bootstrap-server localhost:9092
`

应输出 22-transactions。

### 3.4 Flink

**安装路径**：D:\flink\

> Flink 提供的是 .sh 脚本，Windows 下需通过 Git Bash 或 WSL 执行。

**① 启动 JobManager**：
`ash
D:\flink\bin\jobmanager.sh start
`

**② 启动 TaskManager**：
`ash
D:\flink\bin\taskmanager.sh start
`

**③ 验证**：

浏览器打开 http://localhost:8081，看到 Flink Dashboard 即成功。

**④ 停止**：
`ash
D:\flink\bin\jobmanager.sh stop
D:\flink\bin\taskmanager.sh stop
`

### 3.5 后端

**项目路径**：D:\a22\backend\

**① 编译打包**：
`ash
cd D:\a22\backend
mvn clean package -DskipTests
`

**② 启动方式一：Maven 运行**：
`ash
mvn spring-boot:run
`

**③ 启动方式二：JAR 运行**：
`ash
java -jar target/stream-task-platform-0.0.1-SNAPSHOT.jar --spring.datasource.password=123456
`

**④ 启动方式三：IDEA 运行**：
- 打开项目 D:\a22\backend
- 运行主类 com.a22.platform.PlatformApplication

**⑤ 验证**：
`ash
curl http://localhost:8080/api/tasks
`

返回 JSON 数组即正常。

**默认端口**：8080

### 3.6 前端

**项目路径**：D:\a22\frontend\

**① 安装依赖**：
`ash
cd D:\a22\frontend
npm ci
`

**② 启动开发服务器**：
`ash
npm run dev
`

**③ 验证**：

浏览器打开 http://localhost:5173

**④ 生产构建**：
`ash
npm run build
`

产物在 dist/ 目录，可用 Nginx 托管。

## 8. 常见问题

### 8.1 后端启动报 Communications link failure

**原因**：MySQL 未启动或端口不对。  
**解决**：
`ash
net start mysql84
`

### 8.2 后端启动报 Connection refused: localhost:6379

**原因**：Redis 未启动。  
**解决**：
`ash
redis-server
`

### 8.3 Kafka 消费者连不上

**原因**：Zookeeper 或 Kafka 未启动。  
**解决**：按顺序先启动 Zookeeper，再启动 Kafka。

### 8.4 Flink Dashboard 打不开

**原因**：Flink 未启动或端口被占用。  
**解决**：
`ash
D:\flink\bin\jobmanager.sh start
D:\flink\bin\taskmanager.sh start
`

### 8.5 前端页面空白 / 接口 404

**原因**：后端未启动。  
**解决**：确保 http://localhost:8080/api/tasks 能正常返回数据。

### 8.6 任务执行报 只有已发布任务可以启动

**原因**：任务处于草稿状态。  
**解决**：系统已内置自动发布逻辑，重新编译后端即可。

### 8.7 Flink TaskManager 在 Windows 下启动失败

**原因**：Flink 使用 .sh 脚本，Windows 原生不支持。  
**解决**：使用 Git Bash 或 WSL 执行，或使用 Docker 方式部署。
