## 3. 服务启动范围

### CSV 单机测试

```powershell
docker compose up -d mysql redis
```

CSV 单机测试不得启动 Kafka、Flink 或 OceanBase。Compose 已通过 profile 将三者从默认启动范围移除。

### Kafka-Flink 压力测试

```powershell
docker compose --profile streaming up -d kafka jobmanager taskmanager
```

### OceanBase 可选测试

```powershell
docker compose --profile oceanbase up -d oceanbase
```

## 4. 尚未满足的硬件与系统项

1. **内存不足**：宿主机总内存约 16 GiB，无法安全承载固定 32 GiB 客户机并同时保证宿主机稳定。建议将宿主机物理内存升级到至少 48 GiB，推荐 64 GiB；升级前不得把 `memsize` 强制改为 `32768`。
2. **存储介质不符**：当前唯一物理盘是 NVMe SSD，没有可用物理 HDD。需增加内部 SATA HDD，并在虚拟机关机后将目标 VMDK 迁移到 HDD；迁移前必须备份虚拟机。
3. **操作系统不符**：当前客户机是 Ubuntu 24.04.5 Desktop，不是 Ubuntu Server 22.04。重装会改变系统和软件状态，必须先获得用户确认并备份客户机数据。
4. **客户机分区未扩展**：VMware 只扩展了虚拟磁盘，客户机分区和 ext4 文件系统仍需开机后使用 `growpart` 与 `resize2fs` 扩展；该操作需在确认客户机账号和备份后执行。
5. **文件系统待核验**：关机状态无法可靠确认客户机文件系统，不能把目标 ext4 写成当前事实。

## 5. 每轮测试前检查

```powershell
# 必须返回 Total running VMs: 0 后再修改磁盘或 VMX
& 'D:\vmware\vmrun.exe' list

# 核对内存、磁盘型号与介质
Get-CimInstance Win32_ComputerSystem | Select-Object TotalPhysicalMemory
Get-PhysicalDisk | Select-Object FriendlyName,MediaType,Size,HealthStatus

# 核对软件版本
java -version
mvn -version
node --version
npm --version

# 校验 Compose 配置
docker compose config --quiet
```

测试开始前还应关闭浏览器下载、编译、视频、虚拟机克隆和大文件复制等宿主机重负载任务，并记录当时的 CPU、可用内存和磁盘可用空间。
